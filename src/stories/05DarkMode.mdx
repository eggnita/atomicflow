# Dark Mode

AtomicFlow provides comprehensive dark mode support with flexible configuration options.

## 🌙 **How Dark Mode Works**

AtomicFlow uses **data attributes** to manage themes, making it compatible with most modern frameworks and libraries.

### Theme Detection

```javascript
// Automatic system preference detection
const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;

// Apply theme
document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light');
```

## 🔧 **Implementation in Your App**

### React Implementation

```tsx
import { useEffect, useState } from 'react';

function ThemeProvider({ children }) {
  const [theme, setTheme] = useState('system');

  useEffect(() => {
    const root = document.documentElement;
    
    if (theme === 'system') {
      const systemTheme = window.matchMedia('(prefers-color-scheme: dark)').matches 
        ? 'dark' 
        : 'light';
      root.setAttribute('data-theme', systemTheme);
    } else {
      root.setAttribute('data-theme', theme);
    }
  }, [theme]);

  return (
    <div data-theme={theme}>
      {children}
    </div>
  );
}
```

### Next.js Implementation

For Next.js apps, use `next-themes` for better SSR support:

```bash
npm install next-themes
```

```tsx
// pages/_app.tsx
import { ThemeProvider } from 'next-themes';
import 'atomicflow/index.css';

function MyApp({ Component, pageProps }) {
  return (
    <ThemeProvider attribute="data-theme" defaultTheme="system">
      <Component {...pageProps} />
    </ThemeProvider>
  );
}
```
